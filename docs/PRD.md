# 产品需求文档 (PRD)：NHY AI 创智平台 (产品创新与资产管理)

## 1. 文档概述
* **产品名称**：NHY AI 创智平台 (NHY AI-PLM)
* **文档版本**：V0.0.1 (MVP版)
* **编写人**：luffyzh
* **更新日期**：2026-08-10
* **文档状态**：待评审

## 2. 业务背景与目标
### 2.1 业务背景
NHY 正处于产品化转型期，积累了大量技术与项目经验，但面临三大痛点：
1. **创新门槛高**：一线员工有业务洞察，但缺乏结构化表达（写 PRD）的能力，导致好想法难以孵化。
2. **管理不规范**：产品从原型到量产（EVT/DVT/PVT）缺乏统一的阶段卡点和文档规范，PMO 汇总进度耗时耗力。
3. **资产难复用**：产品信息分散，跨部门沟通、向上汇报、对外宣传时，反复人肉整理材料，口径不一。

### 2.2 产品目标
打造一个基于 AI 的一站式产品创新与管理平台，实现：
* **想法结构化**：通过 AI 引导表单，让全员皆可低门槛提交标准产品提案。
* **流程标准化**：规范产品全生命周期管理，实现阶段卡点、文档齐全、AI 自动汇总进度。
* **资产可复用**：沉淀公司级产品知识库，AI 一键生成多场景汇报/宣传材料。

## 3. 目标用户与权限角色
| 角色名称 | 核心诉求 | 系统权限边界 |
| --- | --- | --- |
| **全员/发起人** | 提交想法，希望被看见和落地 | 提交提案、查看公开产品地图、基础检索 |
| **产品经理 (PM)** | 挖掘需求，推进立项，管理产品线 | 认领提案、编辑 PRD、管理产品阶段与文档 |
| **项目经理 (PMO)**| 监控进度，把控风险，组织评审 | 设置阶段卡点、查看数据看板、导出周报 |
| **管理层** | 掌握产品大盘，进行战略决策 | 查看产品大盘、审批核心节点、查看高潜机会 |
| **售前/市场** | 获取最新产品资料，生成宣传文案 | 访问产品详情、使用 AI 资料生成器 |

## 4. 核心业务流程
### 4.1 想法孵化到立项流程
`全员提交模糊想法` -> `AI 引导追问补充` -> `AI 生成标准 PRD 初稿` -> `进入产品机会池` -> `PM 认领并完善` -> `发起立项评审` -> `立项成功，建立产品线`

### 4.2 产品线推进流程
`进入当前阶段 (如原型期)` -> `分配阶段必填文档/任务` -> `成员日常同步进度` -> `AI 自动生成周报` -> `触发阶段评审卡点` -> `评审通过，进入下一阶段 (如 EVT)`

## 5. 功能需求说明

### 模块一：产品创意中心 (Idea Hub)
**1.1 渐进式想法提交表单 (AI Wizard)**
* **功能描述**：提供分步表单，引导用户输入产品定位、目标用户、痛点、核心功能。
* **AI 交互规则**：用户输入简短描述后，系统触发 AI 追问（如：“您提到的痛点，具体是在什么业务场景下发生的？”），用户补充后进入下一步。
* **数据校验**：核心字段必填，字数限制（防冗余）。

**1.2 AI PRD 生成器**
* **功能描述**：基于表单收集的结构化数据，后台组装 Prompt，调用大模型生成 `PRD.md`。
* **业务规则**：
  * 生成的 PRD 必须包含：背景、用户、竞品分析、MVP 功能列表。
  * 支持双栏视图：左侧 Markdown 渲染，右侧 AI 对话框支持“局部重绘”（如指令：“重写竞品分析部分”）。
  * 支持人工手动修改文本。

**1.3 产品机会池 (Opportunity Pool)**
* **功能描述**：展示所有已生成的提案卡片。支持按热度、业务线筛选。
* **业务规则**：PM 角色可点击“认领”，认领后状态变更为“孵化中”，并可发起线上立项评审流。

### 模块二：产品线管理中心 (PLM Center)
**2.1 门径管理 (Phase-Gate)**
* **功能描述**：立项后的产品进入生命周期看板。预设阶段：概念期 -> 原型期 -> 实验室样机(EVT) -> 工程样机(DVT) -> 量产(MP)。
* **业务规则**：每个阶段流转必须满足前置条件（如 DVT 阶段必须上传《BOM表》和《测试报告》），否则无法发起阶段评审。

**2.2 智能进度与周报生成 (AI PMO)**
* **功能描述**：成员通过类似“发动态”的形式，随时记录今日进展与风险。
* **AI 交互规则**：每周五 16:00，系统底层大模型抓取该产品线下本周所有动态、文档更新记录，自动生成结构化《产品周报》（含进展、风险、下周计划），并推送给相关干系人。

### 模块三：产品资产与知识门户 (Asset Portal)
**3.1 产品全景地图与详情页**
* **功能描述**：企业级产品黄页。展示所有正式产品。
* **详情页内容**：一句话介绍、当前阶段、负责人、核心指标、关联文档库（PRD、设计图、操作手册）。

**3.2 AI 场景化材料生成器**
* **功能描述**：用户在产品详情页，可选择目标场景，AI 自动抓取当前产品最新资料生成文案。
* **支持场景**：
  1. 领导汇报版 (侧重进度、风险、里程碑)
  2. 售前沟通版 (侧重客户价值、竞品优势)
  3. 外部宣传版 (侧重亮点、通俗易懂)
* **业务规则**：生成的对外宣传材料，必须带有“未经审核，仅供参考”水印，需一键提交市场部审核后方可对外使用。

## 6. 非功能需求
* **性能需求**：AI 生成 PRD 响应时间不超过 15 秒；常规页面加载不超过 2 秒。
* **安全需求**：接入的底层大模型必须为私有化部署或企业级安全接口，确保公司商业机密（产品想法、BOM、核心数据）不外泄。
* **兼容性**：Web 端适配主流浏览器（Chrome, Edge），移动端（企微/钉钉/飞书）支持查看产品大盘和提交想法。

## 7. MVP 版本范围界定 (Phase 1)
为了快速验证价值，V1.0 MVP 版本**仅包含以下核心闭环**：
1. **做**：渐进式想法提交表单、AI PRD 生成与编辑、基础产品机会池。
2. **做**：产品详情页基础展示、AI 生成“领导汇报”与“跨部门沟通”两类材料。
3. **不做**：复杂的硬件 EVT/DVT 阶段强卡点流转（一期仅做轻量级状态标记）。
4. **不做**：外部宣传材料的复杂审批流（一期仅限内部查阅使用）。
