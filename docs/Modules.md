# 原型系统生成指令 (Agents.md)：NHY AI 创智平台

## 1. 文档使用说明
本文档包含用于驱动 AI 编程助手（如 Cursor、v0、Bolt 等）生成前端原型的结构化提示词。
**使用方法**：
1. 先将【全局系统设定】发给 AI，让其理解技术栈和全局 UI 规范。
2. 按模块顺序，将【模块生成指令】逐个发给 AI，逐步构建完整的 Admin 系统。

---

## 2. 全局系统设定 (Global System Prompt)

**请将以下内容作为 System Prompt 发送给 AI 助手：**

> 你现在是一个资深的前端架构师和 UI/UX 设计师。请帮我开发一个名为“NHY AI 创智平台（研究院效能中台）”的 B 端后台管理系统原型。
> 
> **技术栈要求：**
> * 框架：React 18 + TypeScript
> * 样式：Tailwind CSS
> * 组件库：Shadcn UI (或 Ant Design)
> * 图表库：Recharts
> * 图标：Lucide React
> 
> **全局 UI/UX 规范：**
> 1. **整体布局**：经典的 Admin 左右分栏布局。左侧为深色垂直导航菜单（可折叠），顶部为白色 Header（包含面包屑、全局搜索、消息通知铃铛、用户头像），右侧下方为灰色背景的主内容区（包含白色卡片容器）。
> 2. **色彩规范**：主色调使用科技蓝（Primary Blue, 类似 Tailwind 的 blue-600），状态色使用标准语义（成功-绿，警告-黄，危险-红，中性-灰）。
> 3. **交互规范**：所有的表格（Table）上方必须有查询表单（Search Form）和操作按钮区。删除操作必须有二次确认弹窗。
> 4. **响应式**：主内容区需适配 1080p 及以上分辨率，不需要考虑移动端适配。

---

## 3. 模块生成指令 (Module Prompts)

### 3.1 基础框架与路由布局 (Layout)
**Prompt:**
> 请基于全局设定，帮我生成系统的基础 Layout 组件。
> 1. 左侧菜单包含以下导航项，请带上合适的 Lucide 图标：
>    - 产品创意中心 (子菜单：创意大盘、我的创意)
>    - 产品线管理 (子菜单：产品大盘、周报管理)
>    - 资产与知识门户 (子菜单：资产检索、生成记录)
>    - 部门效能管理 (子菜单：组织架构、效能指标、部门大盘)
>    - 系统设置 (子菜单：用户管理、角色权限、数据字典)
> 2. 顶部 Header 包含：左侧折叠按钮和面包屑，右侧包含一个带有红点的消息铃铛，以及用户头像下拉菜单。
> 3. 主内容区请先放一个欢迎卡片（Welcome Card），显示“欢迎使用 NHY AI 创智平台”。

### 3.2 模块一：产品创意中心 - 创意向导与 PRD 生成
**Prompt:**
> 请帮我生成“产品创意中心 -> 新建创意”的页面。这是一个全屏的沉浸式工作台，分为左右两栏布局：
> 
> **左侧：AI 交互与表单区 (占 40% 宽度)**
> 1. 顶部是一个步骤条 (Steps)：1. 基础定位 -> 2. 痛点场景 -> 3. 核心功能 -> 4. 生成 PRD。
> 2. 中间是当前步骤的表单输入框。
> 3. 下方是一个类似 ChatGPT 的对话框，显示 AI 的追问（例如：“请问这个痛点主要影响哪些岗位？”），并提供输入框供用户回答补充。
> 
> **右侧：PRD 实时预览区 (占 60% 宽度)**
> 1. 这是一个 Markdown 渲染区域。
> 2. 顶部有操作按钮：[局部重写]、[保存草稿]、[提交立项评审]（主按钮）。
> 3. 占位内容请用一段标准的 Markdown PRD 文本（包含背景、用户、功能列表）填充。

### 3.3 模块二：产品线管理 - 矩阵式产品大盘
**Prompt:**
> 请帮我生成“产品线管理 -> 产品大盘”的列表页面。
> 1. **顶部搜索区**：包含输入框（产品名称）、下拉选择（阶段：原型/EVT/DVT/MP）、下拉选择（参战部门）、下拉选择（健康度）。
> 2. **操作区**：一个醒目的 [新建产品线/立项] 按钮。
> 3. **数据表格 (Table)**：
>    - 列1：产品名称 (加粗，可点击)
>    - 列2：产品经理 (带头像的标签)
>    - 列3：参战部门 (使用多个 Tag 展示，如“硬件部”、“算法部”)
>    - 列4：当前阶段 (使用带颜色的 Badge，如 EVT 为蓝色)
>    - 列5：健康度 (使用状态圆点，绿代表正常，红代表延期)
>    - 列6：操作 (进入工作台、编辑、归档)
> 4. **新建立项弹窗 (Modal)**：点击新建按钮弹出的表单。包含基础信息，以及一个“参战部门选择”的多选框。选中部门后，下方动态出现该部门的“指标期望值”输入框（例如：硬件部-打样直通率目标 [%]）。

### 3.4 模块二：产品线管理 - 阶段与效能工作台
**Prompt:**
> 请帮我生成单个产品的“阶段工作台”页面。页面顶部展示产品名称、当前阶段和整体进度条。主体内容使用 Tabs 组件分为三个面板：
> 
> **Tab 1: 阶段门径管理 (Phase-Gate)**
> 展示一个卡片列表，列出当前阶段（如 EVT 阶段）必须提交的文档。每行包含：文档名称、负责部门、状态（已上传/未上传）、上传按钮。底部有一个 [发起阶段评审] 按钮（如果状态有未上传，按钮置灰）。
> 
> **Tab 2: 成员进度流 (Timeline)**
> 使用时间轴 (Timeline) 组件，展示团队成员的日常汇报。每条记录包含：汇报人、时间、内容文本、风险标签（如有）。
> 
> **Tab 3: 部门效能追踪 (Metrics Tracker)**
> 展示一个表格，对比各参战部门在当前项目中的表现。列包含：部门名称、考核指标、期望目标值、当前实际值、状态（达标为绿色，未达标为红色）。

### 3.5 模块三：产品资产门户 - AI 场景化生成
**Prompt:**
> 请帮我生成“资产与知识门户”页面。
> 1. 页面上方是一个巨大的搜索框，带有“AI 智能检索”的提示字样。
> 2. 下方是产品卡片网格 (Grid 布局)。每个卡片展示：产品名称、简介、阶段标签、负责人。
> 3. 卡片底部有两个操作按钮：[查看详情] 和 [AI 生成材料]。
> 4. **AI 生成弹窗 (Modal)**：点击 [AI 生成材料] 后弹出。
>    - 左侧选择生成场景（单选：领导汇报版、跨部门沟通版、对外宣传版）。
>    - 右侧显示生成进度 loading 动画。
>    - 生成完成后，右侧展示生成的 Markdown 文本，并提供 [复制] 和 [导出 Word/PPT] 按钮。如果是对外宣传版，额外显示一个 [提交市场部审核] 按钮。

### 3.6 模块四：部门与效能管理 - 组织架构与大盘
**Prompt:**
> 请帮我生成“部门效能管理”的两个核心页面。
> 
> **页面 1：组织架构管理 (左右分栏)**
> - 左侧 (占 30%)：展示部门树形控件 (Tree)，如“研究院 -> 硬件部 / 软件部 / 产品部”。
> - 右侧 (占 70%)：展示选中部门的详细信息和成员列表 (Table)，包含添加成员按钮。
> 
> **页面 2：部门效能大盘 (Dashboard)**
> - 顶部：部门选择器（下拉框）。
> - 核心数据卡片 (Cards)：参与项目总数、延期项目数、综合效能得分。
> - 图表区 (使用 Recharts)：
>   - 左侧放一个雷达图 (Radar Chart)，展示该部门在各项核心指标（如交付率、直通率、成本控制）上的平均得分。
>   - 右侧放一个柱状图 (Bar Chart)，展示该部门在各个具体项目中的效能对比。
> - 底部列表：展示该部门当前存在“效能瓶颈”或“延期风险”的具体项目任务清单，标红预警。
